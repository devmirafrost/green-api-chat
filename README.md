# GREEN-API Chat

Тестовое задание: пользовательский интерфейс для отправки и получения сообщений в мессенджере MAX через GREEN-API.

## 🛠️ Стек

- React 18 + TypeScript
- Vite
- ESLint + Prettier
- GitHub Actions (CI)

## 🚀 Локальный запуск

```bash
npm install
npm run dev
```
